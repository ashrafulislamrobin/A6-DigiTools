# DigiTools - Digital Tools Marketplace

DigiTools is a sleek, single-page web application designed for creators to explore and acquire premium digital assets. From AI-powered resume builders to robust social media schedulers, the platform provides a seamless browsing and shopping experience with real-time feedback and a modern, high-conversion layout.

### Technologies Used

* **React.js & Vite** – For building a high-performance, component-based user interface with lightning-fast load times.
* **Tailwind CSS & DaisyUI** – For crafting a pixel-perfect, responsive design and consistent UI components without custom CSS bloat.
* **React Toastify** – Provides instant, human-friendly visual feedback for every user action, such as adding or removing items.
* **Font Awesome** – To ensure a professional and recognizable iconography across the entire application.

### Key Features

* **Dynamic Cart Management** – A seamless toggle system lets users switch between the product gallery and their active cart, with real-time price calculations and a live item counter.
* **Interactive User Feedback** – Integrated toast notifications confirm every interaction from adding a tool to proceeding to checkout, so the user is never left guessing.
* **Fully Responsive Architecture** – A mobile-first design approach featuring a 3-column product grid, gradient pricing cards, and a detailed footer that scales perfectly from smartphones to desktops.
